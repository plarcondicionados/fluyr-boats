Organizador de fotos do site

Como usar: arraste cada foto ou vídeo para a seção do site em que ele deve aparecer (ou use o seletor embaixo de cada item). Dentro de uma seção, a ordem em que você deixar é a ordem do site: solte um item em cima de outro para colocá-lo antes dele. Clique em ⤢ para ver em tamanho grande ou assistir ao vídeo. Quando terminar, clique em Salvar organização: o site é atualizado na hora (com o site aberto em npm run dev). Vídeos novos levam alguns segundos para serem convertidos.
